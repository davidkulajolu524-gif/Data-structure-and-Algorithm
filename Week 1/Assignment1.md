Real-Life Applications of a Stack
A Stack is a data structure that works on the LIFO (Last-In, First-Out) rule. It works just like a stack of plates in a cafeteria: the last plate you place on top is the first plate you pick up.

Where stacks are actually used:

1. Undo (Ctrl + Z) in Word or VS Code: Every time you type a word or delete something, the program adds that action to the top of a stack. When you press Ctrl + Z, it removes the very last thing you did first.

2. The "Back" Button on a Web Browser: When you move from Google to Wikipedia and then to YouTube, your browser stacks those pages up. Clicking the Back button removes YouTube from the top of the stack and takes you back to Wikipedia.

3. Mobile App Screen Navigation: When you open WhatsApp, click a chat, and then view someone's profile picture, each screen is placed on a stack. Pressing the back button on your phone closes the most recent screen first.

4. Checking Brackets in Code Editors: When we write code with brackets like ((a + b) * c), the compiler uses a stack to check if every opening bracket ( has a matching closing bracket ) in the right order.

5. Function Calls in Programming: When function A calls function B, the computer puts function A on a "call stack" so it remembers where to return as soon as function B finishes running.
